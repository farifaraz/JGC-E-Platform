# JGC E-Platform App

Vercel-ready static web app for JGC e-platform forms and equipment inspection register.

## Publish on Vercel
1. Go to https://vercel.com/new
2. Upload this project folder or import it from GitHub.
3. Framework Preset: Vite
4. Build Command: `npm run build`
5. Output Directory: `dist`
6. Click Deploy.

## Local Test
```bash
npm install
npm run dev
```

The Excel register is stored in `/public/JGC_Equipment_Inspection_Register.xlsm`.
